# Project Instructions for Codex

## Project Goal

This is a Building Gadget / Minecraft base template planner for ATM10 TTS. The goal is to let the user design modular structures, preview them in a simple Minecraft-like renderer, and eventually export or manage Building Gadget-compatible templates.

## Development Rules

- Work only on the current branch.
- Make small, focused changes.
- Do not rewrite large parts of the app unless explicitly asked.
- Preserve existing working features.
- Before editing, explain which files you plan to change.
- After editing, summarize exactly what changed.
- Prefer simple, maintainable code over clever abstractions.
- Keep UI changes functional and readable.
- Do not remove Claude’s existing features unless asked.
